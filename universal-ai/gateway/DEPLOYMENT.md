# Central deployment
Use a single Cloudflare Workers Builds Git connection to this repository, root directory universal-ai/gateway, deploy command npx wrangler deploy. Do not connect until production gateway and quota tests are complete. The current worker.mjs deliberately fails closed without its quota service. Existing deployed pilot is separate from this source and must not be overwritten prematurely. The reusable client never receives secrets and falls back locally until a public gateway is enabled. Private knowledge requires authenticated server-side access, not public client configuration. No per-website Cloudflare setup is intended; new public applications will be registered in central source and deployed through the same connection.
